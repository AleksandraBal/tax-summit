AI & Tax

Working with LLMs in tax practice

Dr Aleksandra Bal
10 September 2026

Where AI Actually Is Right Now

  • New models every week
  • Open-weight models: good enough, far cheaper
  • From assistive to autonomous
  • AGI: forecasts vary by decades

We Got Faster. We Didn't Get Freer.

  • Keeping up with AI is a second job
  • Real gains: drafting, summarizing, research
  • More output, not more time
  • AI slop: unreviewed drafts passed on

Do You Know How Gen AI Works?

  • How does its web search actually work?
  • Does it know when it doesn't know?
  • Does it learn from you?
  • The tool is fine. The gap is understanding.

Match the Model to the Task

  • Three tiers: frontier, workhorse, light
  • Most tax work runs fine on a workhorse
  • Reasoning models to analyse, fast models to draft
  • The newest model is rarely the right one

Chat Is Flat. Everything Else Is Metered.

  • Your subscription is not the whole cost
  • Agents pay per call — and they loop
  • Top-tier models are billed separately now
  • Set a spending cap before you build

The Model Only Sees What's in the Window

  • Every conversation has a memory limit
  • The middle gets the least attention
  • Feed it sections, not whole documents
  • Summarize, then start fresh

How to Ask

1

Frame it

Context, examples, structure

2

Define done

Format, success criteria, permission to say “I don't know”

3

Work the loop

Questions first, edit—don't stack, review adversarially

4

Start over when it drifts

Cheaper than arguing with it

The App Is Not the Model

  • The model knows only what you put in front of it
  • Memory, custom instructions, web search — those are app layers
  • Projects: shared files across chats, for work you repeat
  • Use a generalist you know well; specialists only when it fails

Not Everything Needs an Agent

Workflow

  • Fixed steps, every time
  • Predictable
  • Breaks on exceptions

AI workflow

  • Fixed steps, one uses AI
  • Handles the messy part
  • Stays auditable

Agent

  • A goal, not a path
  • Plans and acts
  • Different route each run

If you remember four things

  1. Match the model to the task
  2. Ask it what it needs before it drafts
  3. Do the thinking; let it polish
  4. Set up shared context for work you repeat
